실험 설계와 해석

20거래일 예측 구간은 서로 겹칩니다. 표본은 독립적이지 않으며, 오차 범위는 미래 포함률을 보장하지 않습니다.

① 2018년 액면분할 이후 원종가만 사용합니다. 입력 길이: 5, 20, 60, 100, 250거래일. 각 입력의 일별 수익률로 20거래일 뒤 수익률을 학습한 뒤 마지막 종가에 적용합니다.

② 학습 → 검증: 2023년 말까지 → 2024년, 2024년 말까지 → 2025년의 확장 학습. Ridge 정규화 계수 1·100·10000을 검증으로 선택합니다. Random Forest는 트리 160개, 깊이 5, 최소 리프 25, 시드 42로 고정합니다. 모든 비교는 250거래일 이력이 있는 동일 날짜를 사용합니다.

③ 최종 모델: 2025년까지 재학습 후 고정. 2026년 각 목표 날짜의 예측에는 20거래일 전 기준일까지의 실제 종가만 입력합니다. 2026년 기준일에서 20거래일 뒤를 직접 예측합니다. 목표 날짜와 기준일 모두 2026년인 경우만 테스트합니다. 학습에는 2025년까지 목표 종가가 확정된 표본만 사용합니다.

④ 표시 구간: 과거 검증의 절대 상대 오차 90백분위로 만든 경험적 오차 범위입니다. 2026년이나 미래에서 90% 포함을 보장하지 않습니다. 주가 수준 변화, 뉴스, 거래량, 시장 지수는 반영하지 않습니다.
