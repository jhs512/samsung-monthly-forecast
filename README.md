# 삼성전자 한 달 뒤 종가 예측

한 달 = 20거래일. 별도 프로젝트이며 다음 거래일 모델을 재사용하지 않고 20거래일 수익률로 새로 학습합니다.

Python 3.12:
```sh
pip install -r requirements.txt
python train.py --as-of 2026-10-08
python verify.py
python -m http.server 8000 --directory docs
```

종가 입력 길이 5/20/60/100/250거래일, Ridge(alpha 1/100/10000)와 Random Forest(160 trees, depth 5, min leaf 25, seed 42), 기준일 종가 유지 비교.

2018년 액면분할 이후 Yahoo Finance 005930.KS 원종가. 수익률 특징(w-1개)으로 기준일에서 20거래일 뒤 수익률을 직접 예측합니다. 2024/2025년 확장 검증의 MAE로 선택합니다. 각 검증년 이전에 목표 종가가 확정된 표본으로 학습하며 검증의 기준일과 목표 날짜 모두 해당 연도여야 합니다. 최종 학습은 목표 날짜가 2025년까지인 표본만 사용합니다. 2026년 기준일과 2026년 목표 날짜 모두 충족한 20거래일 예측만 테스트합니다. 따라서 2026년 첫 20거래일 목표와 마지막 20거래일 기준은 제외됩니다.

무작위 날짜 비교는 실제 목표 종가, 20거래일 전 기준일 종가, 학습 모델 예측 및 각 오차를 보여줍니다. 모델 변경 시 날짜는 유지합니다. 개별 날짜의 승패는 전체 성능을 의미하지 않습니다.

2026년 미확보 미래 종가는 평가하지 않습니다. 가격 데이터는 data/yahoo.json에 원본, data/close.csv 및 docs/close.csv에 사용 표본으로 보관합니다. 브라우저 추론은 서버에 입력을 전송하지 않습니다. 검증 상대 절대 오차의 90백분위 범위는 미래 포함률을 보장하지 않습니다. 20거래일 구간이 겹치므로 표본 오차는 독립적이지 않습니다.

GitHub Actions workflow가 docs 폴더를 Pages로 게시합니다. 학습과 다운로드 데이터는 저장된 원본으로 재현됩니다. --refresh는 원본을 다시 다운로드합니다.
